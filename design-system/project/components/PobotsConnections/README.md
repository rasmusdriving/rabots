# Pobots connections

In Settings. Use a quiet list row for each connection: the local name, current state, last message and actions. Waiting copy, connectivity and pause states share the same space. Pair and remove from a dialog above the page. Pairing fields are single-line; Copy has a stable size. Keep the rows readable with long names and give buttons room to wrap on a phone.

Each row has a line for how long the connection lasts, always there so the row keeps its height: "Ends in 23 hours", "Ends in 29 days", "Lasts until removed", "Will end 24 hours after connecting", and for an ended one "To connect again, pair with new codes". The line is read again each minute; it never moves the row. **Ends after** is a select in the pairing dialog and in **Edit** (name and ends after), with 24 hours, 30 days and Never; Never is the default. An ended row offers only Remove.

Files from another Pobots sit under its message in the chat, on the left like the message, with the same file chips as the person's attachments.

Each connection belongs to one of the person's bots (the main bot unless chosen). The row says so under the name, with the bot's small face: "Belongs to Skifte"; while that bot is on vacation, "Belongs to Skifte, on vacation. Messages wait until it is back". The line is always there, so the row keeps its height. **Belongs to** is a select in the pairing dialog and in **Edit**, the main bot first. A message from another Pobots says in its head whose connection it came on: "From another Pobots, on Skifte's connection".
