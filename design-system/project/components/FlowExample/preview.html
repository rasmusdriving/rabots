What the flow sends, open

For each tagged message, the flow posts JSON like this. messageId, from.email, and text or html are needed; the rest may be left out. context holds the messages before it, oldest first.

{
  "messageId": "1794391578003",
  "threadId": "1794391500000",
  "from": {
    "name": "Ada Example",
    "email": "ada@example.com"
  },
  "text": "Po can you draft the agenda for Thursday",
  "html": "<p><at id=\"0\">Po</at> can you draft the agenda for Thursday</p>",
  "mentions": [
    "Po"
  ],
  "context": [
    {
      "from": "Bo Example",
      "text": "We need an agenda for Thursday.",
      "at": "2026-11-11T09:58:00Z"
    }
  ],
  "at": "2026-11-11T10:06:20Z",
  "link": "https://teams.example.com/l/message/..."
}
Answers go to the address for answers as JSON with channelId, messageId, threadId, bot, text and html. A bot's own new post goes there too, with kind set to post and no messageId or threadId; the flow answers with the new post's messageId.
