# Pobots Usage

Usage sits in Settings. The scope and provider are above the view, range and refresh controls. Cost and Tokens open with the large total and a quiet session count, then the provider rows and trend. Totals, stacked bars and a breakdown by model or day follow in that order. The estimate uses API prices; sessions are counted from this computer's saved history.

Keep the last figures in place and fade them during a read. Use tabular numerals and put the selected state on the control, never on the chart. Let the chart's marks repeat the provider dot. Limits has a surface per limit with the pooled percentage and a bar and reset time for each account.

At phone width show one column, with a labelled stack for each table row. Keep view, range and refresh targets large enough to tap. Use quiet fills and spacing for grouping.

Name the sources directly above the plan cards. Put “This Mac” next to a local provider. Keep the hub cards in place while refreshing, and put a newly read local group after them. Use the same quiet surface for Codex credits, with separate labels for credits left and reset credits left. Keep account details to initials on pooled credit cards.
