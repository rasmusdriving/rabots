A button starts one action and says what that action is.

- **Primary** (`pb-btn pb-btn-primary`): the one action a view is for. One per view, one per card.
- **Secondary** (`pb-btn`): the alternative next to a primary.
- **Quiet** (`pb-btn pb-btn-quiet`): low-stakes choices such as "Later" or "Cancel".
- **Danger** (`pb-btn pb-btn-danger`): deleting or denying for good. It stays quiet until hovered.
- **Small** (add `pb-btn-sm`): inside cards in the rail and in dense rows.

You provide the label. Write a verb and its object in sentence case: "Allow once", "Open draft", "Delete bot". Never "OK", "Yes" or "Submit".

A button never changes size or label while it works. Disable it and let the bot's status mark show the progress.
