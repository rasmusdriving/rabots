The file list is the left column of a bot's Files tab: its files grouped as Memory, Skills and Other, with the editor beside it.

You provide each file's name for people and its path.

- Each row is the name, with the path under it in mono. The open file is raised, like the open bot in the roster.
- The job is not in this list; it has its own tab.
- "New file" sits at the top as a quiet button. It opens a name field; a plain name goes under `memory/` and gets `.md`.
- Groups with no files are left out. With no files at all, one line says so.
- On a narrow panel the list and the editor take turns, with a quiet "Files" button to go back.
