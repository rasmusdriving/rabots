Who may write to bots in a channel: email addresses as soft rows, each with a quiet "Remove", and a field to add one.

- **Row** (`pb-writer`): the address on a `fill`, in lowercase, broken anywhere so a long one never leaves the row, and a quiet "Remove" (its label names the address for a screen reader). Remove saves at once; the address can be added again.
- **Add** (`pb-add-row`): a field in a well and a small "Add". Enter adds too. The address is trimmed and lowercased. Something that is not an address, or one already on the list, is said in clay under the field ("Write an email address, like name@example.com.", "That address is already on the list.") and nothing is added.
- One line above the rows: "A message from anyone else is refused and reaches no bot." With nobody on the list, that line is replaced by "Nobody can write to bots here yet. Add the email address of each person who may."
- "Saved" beside the section title for a moment after each change.
