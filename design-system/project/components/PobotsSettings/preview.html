This RSA key has 2048 bits. Make one of 4096 bits.
  1. In 1Password, open your private vault and choose New Item, then SSH Key.
  2. Choose Add Private Key, then Generate a New Key, of the kind RSA and the size 4096. Save it.
  3. Copy its public key, paste it in the field above and press Save key.

The key belongs in your private vault, not in a shared one. The private key never leaves 1Password: Pobots only needs the public key, which can lock backups but not open them.
